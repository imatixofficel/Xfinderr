فونت محلی Xfinder
-----------------
Vazirmatn-Black.ttf همان فایل فونت موجود در پروژه است.
CSS از همین فایل استفاده می‌کند و برای وزن‌های دیگر، مرورگر وزن را به صورت خودکار شبیه‌سازی می‌کند.
اگر نسخه کامل Variable/WOFF2 Vazirmatn را دارید می‌توانید آن را با نام Vazirmatn.woff2 در همین پوشه قرار دهید.
